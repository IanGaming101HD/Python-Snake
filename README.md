# Snake Game

Welcome to the Snake Game project, a Python application built using Pygame. This project recreates the classic Snake arcade game where the player controls a growing snake that must eat food while avoiding collisions with itself and the walls.

## Features

* Classic Snake gameplay mechanics
* Smooth movement using keyboard controls
* Random food spawning system
* Score tracking system
* Game over detection and restart functionality

## Prerequisites

Before running the Snake Game, ensure you have the following:

* Python (3.8 or higher recommended)
* pip (Python package manager)
* Pygame library

## Installation

Follow these steps to get your Snake Game up and running:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/imtiazhasan07/snake-game.git
   cd snake-game
   ```

2. **Install dependencies:**
   Install Pygame using pip:

   ```bash
   pip install pygame
   ```

## Usage

To launch the Snake Game, run the following command from the project directory:

```bash id="xk18qa"
python main.py
```

(Replace `main.py` with your actual file name if different.)

Use the arrow keys to control the snake and try to eat as much food as possible without colliding with yourself or the walls.
